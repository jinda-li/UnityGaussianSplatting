# 开发日志 2026-07-15：DroneAI 无人机状态机（占位方块）

分支：`vr-preview`　提交：尚未提交　场景：`projects/GaussianExample-URP/Assets/Forest.unity`

## 背景

Forest 场景此前只有玩家角色，没有任何可交互内容。按整体流程参考图（Drone Approching →
Hover and identify → Pull back and Dive → Death/Survive）开发无人机 AI 的第一版：
状态机 + 占位方块视觉，配合暂停式教学 UI，为后续替换真无人机模型和完整死亡流程打地基。

本次开发全程通过 UnityMCP（mcp-for-unity，`http://127.0.0.1:8080/mcp`）直接操作 Unity
编辑器完成脚本编译检查、prefab 搭建、场景接线和 Play Mode 冒烟测试，没有手写 Editor
菜单脚本，也没有手动在编辑器里拖拽。

## 今天做了什么

1. **DroneAI.cs**（状态机，根节点=重心）：`Search → Identify → Attack` 或
   `Search → Leave → Destroy`。根节点只做 yaw（机身保持水平）。
   - Search：朝可配置的 flyby target 直线飞，到达后悬停继续搜索一段时间，
     仍未发现玩家才转 Leave。
   - 发现判定：距离 + Linecast 无遮挡，且需**持续视线 ≥ 2 秒**（可调）才算发现，
     中途断线计时清零。
   - Identify：飞向玩家、悬停在可配置距离（默认 5m）盯着看，一段时间后进入 Attack。
   - Attack：锁定玩家当前位置沿直线俯冲（中途不修正，可被躲避），启用 trigger
     碰撞体，SphereCast 防高速穿透；撞掩体/地面/玩家都会 `Explode()`，
     撞玩家额外触发 `onPlayerHit` 事件。
   - Leave：搜索无果后直线飞走，默认 10 秒后自我销毁。
   - 所有时长/速度/距离均 `[SerializeField]` 暴露。
2. **DroneMotionSim.cs**：挂在 Graphic 子物体（当前是占位方块），根据根节点帧间速度换算
   pitch/roll 姿态倾斜（不做上下浮动），换真机模型时只需替换这个子物体的 mesh。
3. **DroneSpawner.cs**：游戏开始延迟（默认 20s，可调）在自身位置生成 Drone，随机注入
   flyby target。
4. **DroneLessonUI.cs**：订阅 `DroneAI.StateChanged` 静态事件，按状态在头显前方弹出
   world-space 面板（`Time.timeScale = 0` 暂停），controller 点 OK 恢复；每种状态默认
   全局只弹一次。
5. **Prefab**：`Assets/Prefabs/Drone.prefab`（根节点 kinematic Rigidbody + trigger
   SphereCollider + Graphic 方块）、`Assets/Prefabs/DroneLessonPanel.prefab`
   （World Space Canvas + TrackedDeviceGraphicRaycaster + TMP 标题/正文 + OK 按钮）。
6. **Forest 场景接线**：新增 `DroneAI System`（Spawner、两个 Flyby Target、
   Lesson UI + 面板实例，英文占位文案已填），并补齐场景缺失的 XR UI 输入链路——
   EventSystem + XRUIInputModule、InputActionManager（复用 XRI Default Input
   Actions）、左右手 `NearFarInteractor`（挂在 LeftHandAnchor/RightHandAnchor 下，
   UI 交互已启用）。
7. **Play Mode 冒烟测试**：手动触发生成两只无人机，完整跑通
   `Search → Identify → Attack → 命中玩家 → 爆炸`，三条教学面板各正确弹出一次，
   console 无编译/运行时错误。
