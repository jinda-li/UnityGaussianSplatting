# Where the assets come from

Nothing here is committed. Everything except the tower mesh downloads itself
the first time you build the scene, and the tower mesh is one manual step.

Cache location: `%EIFFEL_ASSETS%`, default
`C:\Users\standalone\Documents\3DGS\Eiffel\assets`. Set the environment
variable to move it. About 1.6 GB once fully populated.

---

## Automatic — Poly Haven (CC0)

`assets.py` pulls these from the public Poly Haven API. No account, no key, no
addon. Just run the scene build and wait:

```bash
blender --background --python scene.py -- --detail 1.0 --texres 2k --out scene.blend
```

Files land under `<cache>/models`, `<cache>/textures` and `<cache>/hdris`, and
are skipped on later runs. If a download is interrupted the partial file is
left as `*.part` and re-fetched, so a failed run is safe to repeat.

| Asset ID | Kind | Used for |
|---|---|---|
| `kloofendal_48d_partly_cloudy_puresky` | HDRI | Sky and all scene lighting |
| `flower_scattered_gravel` | texture | The esplanade the player stands on |
| `leafy_grass` | texture | Lawn base under the scattered clumps |
| `gravel_floor_02` | texture | Allees crossing the lawn |
| `large_sandstone_blocks` | texture | The tower's masonry piers |
| `metal_plate` | texture | Ironwork normal and roughness |
| `rust_coarse_01` | texture | Rust patches on the ironwork |
| `grass_medium_01` | model | Grass clumps (particle instanced) |
| `jacaranda_tree` | model | Main tree of the tree line |
| `tree_small_02` | model | Tree line variety |
| `island_tree_03` | model | Tree line variety |
| `street_lamp_01` | model | Esplanade lamps |
| `painted_wooden_bench` | model | Esplanade benches |
| `shrub_01`, `shrub_03` | model | Currently unused - `build_shrubs` is not called, because these are low-poly proxies that scatter as smooth green domes |

Everything Poly Haven publishes is CC0: no attribution required, commercial use
fine, and safe to redistribute if you ever want to vendor the cache.

## Automatic — generated in this repo

No download and no licence attached; these are built by code every run.

- The tower, when no external mesh is present — `eiffel_tower.py`
- Haussmann apartment blocks, Palais de Chaillot, Ecole Militaire, Tour
  Montparnasse, the Seine and the Pont d'Iena — `cityscape.py`
- Ground discs, allees, sky dome, haze volume — `scene.py`

## Manual — the tower mesh

The one file you have to fetch yourself, because Sketchfab requires a login to
download. It is **not** in the repo: see the licence note below.

1. Open
   <https://sketchfab.com/3d-models/eiffel-tower-model-3d-with-best-quality-c3391c293e70471e9a112f7855adcf2f>
2. Sign in, then **Download 3D Model** → **glTF (.glb)**. Autodesk FBX and OBJ
   also work; `tower_asset.import_tower` handles all three.
3. Put the file at
   `C:\Users\standalone\Documents\3DGS\Eiffel\sketchfab\eiffel_tower_model_3d_with_best_quality.glb`

   Any other path works too - pass `--tower <path>` to `scene.py`, or edit
   `scene.DEFAULT_TOWER`.

About 29 MB. `scene.py` falls back to the procedural tower if the file is
missing, so the build never breaks; it just produces a less accurate tower.

### Licence, and why this one is not committed

Listed as CC-BY by `shatlykxfree`. The geometry checks out - 85 meshes, 696 k
vertices, no zero-area faces, and no textures at all, so no alpha-mapped
foliage tricks. But the source file carries `Archexteriors4_mat_19_Slot_1/2`
material names, which is the naming convention of **Evermotion Archexteriors
vol. 4**, a commercial library. An uploader marking a file CC-BY does not make
it CC-BY if they had no right to license it.

`import_tower` trims everything past a 78 m radius, and the 29,442 faces that
removes are *exactly* the two Archexteriors-named materials - so the mesh that
reaches the scene is entirely `material_0`. That narrows the exposure but does
not establish provenance for the rest.

This fork is a public GitHub repository, so committing the file would be
redistribution. Note that buying a replacement does not change this: standard
TurboSquid and CGTrader licences let you use a model in a production but not
hand the model file on, so no third-party mesh belongs in a public repo.

For a commercially published video, buy a model with a licence you have read,
or use the procedural tower. The pipeline does not care which mesh it gets -
`tower_asset.import_tower` normalises anything to base at z = 0, axis at the
origin and tip at 324 m.

## Not assets, but also outside the repo

Regenerated by the pipeline, so nothing to fetch:

| Path | What | Rebuild |
|---|---|---|
| `…/Eiffel/scene_hdri.blend` | Built scene, ~320 MB | `scene.py`, about 16 s |
| `…/Eiffel/dataset/` | Training images + COLMAP, >1 GB | `render_rig.py`, about 50 min |
| `…/Eiffel/renders/` | Look-dev stills | Throwaway |
| `gsplat/examples/results/` | Trained PLYs, ~1 GB each | `train_eiffel.ps1` |
